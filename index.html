¿Dónde la veo? Argentina

Configuración inicial (una sola vez)

La app usa la API gratuita de TMDB, cuyos datos de disponibilidad por país vienen de JustWatch. Necesitás tu propia clave:

  1. Creá una cuenta gratis en themoviedb.org.
  2. Andá a Configuración → API y pedí una clave (uso personal).
  3. Copiá la API Key o el API Read Access Token y pegala acá.

La clave queda guardada solo en este navegador.

¿En qué plataforma está en Argentina?
